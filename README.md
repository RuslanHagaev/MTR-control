MTR-control - это система контроля материально-технических ресурсов.



О проекте 



MTR-control - веб-приложение для учета и контроля МТР. Проект предназначен для упрощения работы данными, связанными с материальными ценностями и организации их централизованного управления. 

Технология 



1. Python 
2. Django
3. SQLite / PostgreSQL
4. HTML
5. CSS
6. JavaScript
7. Git



Возможности



* Веб-интерфейс для работы системы
* Централизованное управление данными
* Возможность дальнейшего расширения функциональности
* Развитие системы учета МТР



Установка и запуск 

1. Клонирование репозитория 



git clone https://github.com/RuslanHagaev/MTR-control.git

cd MTR-control



Windows:

python -m venv .venv

.venv\\Scripts\\activate



Linux / macOS:

python3 -m venv .venv

source .venv/bin/activate



2\. Запуск сервера 



python manage.py runserver
